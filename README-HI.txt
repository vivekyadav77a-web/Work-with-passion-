MR — Your Career Partner (Bilingual Hindi + English)
इस ZIP में MR लोगो के साथ responsive website/PWA demo है।

Android से:
1. ZIP डाउनलोड करके Extract करें।
2. GitHub पर नया Public repository `mr-employment-platform` बनाएं।
3. ZIP के अंदर की सभी files/folders repository root में upload करें (ZIP file खुद नहीं)।
4. Settings > Pages > Deploy from a branch > main > /(root) > Save।
5. HTTPS URL खुलने पर Chrome menu > Install app / Add to Home Screen।

सीमाएँ:
- यह front-end demo है; sample jobs वास्तविक vacancies नहीं हैं।
- Apply और Post Job forms अभी server/database में save नहीं करते।
- Login, secure accounts, employer verification, admin moderation और real job matching अभी बनाना बाकी है।
- वास्तविक लोगों की निजी जानकारी इस demo में न डालें।
- सार्वजनिक लॉन्च से पहले secure backend, privacy notice, terms, grievance contact और legal review आवश्यक हैं।
